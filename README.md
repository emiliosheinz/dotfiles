# Dotfiles

This repository contains my dotfiles and scripts that I use to setup my devepment environment. I mainly use `bash` and [GNU Stow](https://www.gnu.org/software/stow/) to manage them.


## Usage

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/emiliosheinz/dotfiles/main/init.sh)"
```

## Agent sandbox

`claude` and `opencode` are shell functions that run the agent under a macOS
Seatbelt policy (`sandbox-run`). The policy is generated by agent-safehouse
and scoped to the launch directory; at `~/dev` it also isolates the active
workspace (`~/dev/.worktrees/<workspace>/`) from every other one. Host-only
actions such as opening URLs, `brew install` or tmux go through an approval
broker (`hostrun`). Launching at `~/dev` requires a workspace pane; from
there the agent enlists a repo into the active workspace with
`ws wt add <repo> -b <base>`, which runs on the host without approval. See
[`sandbox/README.md`](sandbox/README.md) for the policy, the broker, the
denial log and the host setup, and `dev/dev/AGENTS.local.md` (with
`CLAUDE.local.md` symlinked to it so both agents share one file) for the
rules agents get at `~/dev`.
